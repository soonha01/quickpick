# QuickPick - 실시간 경매 웹 플랫폼

실시간 경매, 유저 간 채팅, 마이페이지 기능까지 포함된 웹 기반 경매 애플리케이션입니다.

<br>


## 프로젝트 개요

QuickPick은 유저가 상품을 등록하고, 실시간으로 경매에 참여할 수 있는 경매 웹 애플리케이션입니다.  
경매 마감 처리, 채팅, 마이페이지, 사용자 인증 등 경매에 필요한 주요 기능을 직접 구현했습니다.

<br>

## 사용 기술 스택

| 항목        | 기술 |
|-------------|------|
| 언어        | JavaScript |
| 백엔드      | Node.js (Express) |
| 프론트엔드  | HTML, CSS, Bootstrap |
| 템플릿 엔진 | EJS (채팅 페이지에 사용) |
| 데이터베이스 | PostgreSQL |
| DB 연동     | `pg` 모듈 |
| 환경변수 관리 | dotenv |
| 버전관리     | Git, GitHub |
| DB GUI       | pgAdmin |

<br>

## 주요 기능 소개

### 1. 회원가입 / 로그인
- 유효성 검사 포함된 로그인 & 회원가입 구현
- 로그인된 사용자만 경매 등록/입찰 가능

### 2. 경매글 등록/참여
- 상품 경매글 등록 (제목, 시작가, 종료시간 등)
- 입찰 기능 (현재가보다 높은 금액만 가능)
- 마감시간 자동 처리 (서버 주기적 체크 후 상태 변경)

### 3. 마이페이지
- 내가 등록한 상품 목록
- 내가 입찰한 상품 목록
- 상태(마감, 진행중 등) 뱃지로 표시

### 4.  채팅 기능 (EJS)
- 실시간 1:1 채팅 기능
- 사용자 간 커뮤니케이션 가능

<br> 

## 구현한 기능 및 기술


###  경매글 작성
- 사용자 입력값(제목, 설명, 시작가, 마감시간 등) 처리
- 이미지 업로드 기능 구현 (`Multer` 사용, 서버에 파일 저장)
- 업로드된 이미지 경로를 PostgreSQL에 저장
- 글 작성 후 경매 목록에 실시간 반영되도록 처리
- 경매 상태를 DB에서 조회해 **마감 여부 표시**

경매글 작성 기능<br>

###  경매글 리스트
- 등록된 모든 경매글 목록 페이지 구현
- 마감된 경매는 "마감", 진행 중인 경매는 "진행 중" 뱃지로 시각화
- 각 경매글 클릭 시 상세 페이지로 이동 가능
- 마감 시간 기준으로 경매 상태 판별 (`현재 시간 > 마감 시간`)

###  1:1 실시간 채팅
- 경매 상세 페이지에서 "채팅하기" 클릭 시 1:1 채팅방 생성
- `Socket.IO`를 사용하여 웹소켓 기반 실시간 채팅 구현
- 채팅 메시지는 DB에 저장되고, 입장 시 이전 대화 불러오기
- 채팅 UI는 `EJS`로 구현하여 실시간 반응 처리

###  마이페이지
- 로그인된 사용자의 정보(닉네임, 전화번호, 프로필 사진) 조회 및 수정 기능
- 프로필 이미지 업로드 (`Multer` 사용)
- 입력한 정보는 DB에 업데이트되며, 변경 사항은 즉시 반영

###  서버 및 DB 연동
- PostgreSQL 연동 (`pg` 모듈 사용)
- 직접 SQL 쿼리 작성하여 CRUD 처리
- 환경 변수 파일 (`.env`) 사용해 DB 정보 보안
- DB 백업 파일(.backup)로 복원 및 테스트 가능



<br>

###  백엔드 구조 설계
- `Express` 기반 서버 구성
- 라우팅 모듈 별도 분리 (`routes/`)
- 정적 파일(`public/`), EJS 뷰(`views/`), DB(`db.js`) 등 폴더 구조 체계화
- 서버 설정은 `app.js`에서 관리
- 미들웨어 구성 (`body-parser`, `cookie-parser`, `express-session` 등)

<br>

### 프로젝트를 마치며

이번 프로젝트는 제가 처음으로 웹사이트를 직접 기획하고 개발해본 경험이었습니다.  
처음 시작할 땐 과연 제가 이걸 끝까지 해낼 수 있을까 걱정도 많았지만, 현업에 계신 지인의 도움도 받고, 부족한 부분은 직접 공부하면서 하나하나 구현해 나갔습니다.  

함께한 팀원들 모두 웹 개발이 처음이었기 때문에 어려운 점도 많았지만, 그만큼 서로 도우며 성장할 수 있었고, 팀장으로서 중심을 잡고 기능 구현을 이끌어나가며 책임감도 배울 수 있었습니다.  

특히 백엔드 구조를 설계하고 서버와 DB를 연동하며 실제로 서비스가 작동하는 걸 봤을 때, 큰 보람과 재미를 느꼈습니다.  
이 경험을 통해 백엔드 웹 개발자라는 진로를 확신하게 되었고, 앞으로도 계속해서 개발 공부를 이어가고 싶다는 목표가 생겼습니다.
